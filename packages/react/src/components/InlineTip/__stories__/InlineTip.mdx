## Overview

Inline tips are messages embedded within other components that provide an
ambient way to deliver learning content without distracting the user from their
flow.

The package exports three components:

- `InlineTip`: the tip container
- `InlineTipButton`: a pre-styled ghost button for the `action` prop
- `InlineTipLink`: a pre-styled link, with a launch icon, for the `action` prop

## Getting started

Here's a quick example to get you started.

```bash
yarn add @carbon/react
yarn add @carbon-labs/react-inline-tip
```

### JS (via import)

```javascript
import {
  InlineTip,
  InlineTipButton,
} from '@carbon-labs/react-inline-tip/es/index';

function App() {
  return (
    <InlineTip
      title="Use case-specific heading"
      action={<InlineTipButton>Click me</InlineTipButton>}
      onClose={() => {}}>
      <p>
        Use case-specific content that explains the concept or adds context.
      </p>
    </InlineTip>
  );
}

export default App;
```

### SCSS

In your styles file import

```scss
@use '@carbon/react';
@use '@carbon-labs/react-inline-tip/scss/inline-tip';
```

### With an action

Use the `action` prop with `InlineTipButton` or `InlineTipLink` to add a call to
action below the content.

```jsx
<InlineTip
  title="Use case-specific heading"
  action={
    <InlineTipLink href="https://www.ibm.com" target="_blank">
      Learn more
    </InlineTipLink>
  }>
  <p>Use case-specific content.</p>
</InlineTip>
```

### Collapsible

Set `collapsible` to truncate the body text to one line and expose an
expand/collapse button. This is disabled when `renderMedia` is provided.

```jsx
<InlineTip title="Use case-specific heading" collapsible>
  <p>Use case-specific content that explains the concept or adds context.</p>
</InlineTip>
```
