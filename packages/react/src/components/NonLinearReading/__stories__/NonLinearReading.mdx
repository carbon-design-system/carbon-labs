## Overview

Use non-linear reading when space is limited to share a brief, at-a-glance,
summary of a concept that may require more explanation for some users.

The component renders an inline keyword pill. Clicking the keyword expands an
additional definition or explanation inline with the surrounding text.
Definitions can be nested to multiple levels, and support a `dark` theme for use
on gradient or dark-background panels.

## Getting started

Here's a quick example to get you started.

```bash
yarn add @carbon/react
yarn add @carbon-labs/react-non-linear-reading
```

### JS (via import)

```javascript
import { NonLinearReading } from '@carbon-labs/react-non-linear-reading/es/index';

function App() {
  return (
    <>
      XDR Connect's correlation{' '}
      <NonLinearReading definition="This is a technical component that uses a set of rules to process alerts.">
        engine,
      </NonLinearReading>{' '}
      creates a case by processing data from alerts across multiple security
      tools.
    </>
  );
}

export default App;
```

### SCSS

In your styles file import

```scss
@use '@carbon/react';
@use '@carbon-labs/react-non-linear-reading/scss/non-linear-reading';
```
