## Overview

> **Problem statement:** Carbon can show a keyboard shortcut only as a plain
> string in `MenuItem`'s `shortcut` prop. Every product hand-types its own
> glyphs, shows `⌘` to Windows users or `Ctrl` to Mac users, and leaves screen
> readers to announce `⌘` as "place of interest sign". `KeyboardShortcut` takes
> the keys once (`keys={['mod', 'K']}`), shows `⌘K` on macOS and `Ctrl+K`
> elsewhere, and names the combination in words ("Command K"). Its nearest
> Carbon neighbour is `MenuItem.shortcut`, and `kind="plain"` matches it.

It only **displays** a shortcut. Like `MenuItem.shortcut`, it never registers or
listens for the keys.

## Platforms

`mod` is ⌘ on macOS and Ctrl elsewhere. macOS shows glyphs (⌘ ⌥ ⇧ ⌃ ↵ ⌫ ⎋ ←);
Windows and Linux show words (Ctrl, Alt, Shift, Enter). `platform="auto"`
detects it in the browser. A server render cannot know the platform, so it
renders the Windows and Linux words and the browser takes over straight after
hydration. Pass `platform="mac"` or `"other"` when the server knows better, for
example from the request's `User-Agent`.

## Accessibility

- The markup is the HTML standard's own for a key combination: one `<kbd>` per
  key inside an outer `<kbd>`.
- The whole shortcut is named in words, through visually hidden text. A `<kbd>`
  has the generic role, which ARIA 1.2 forbids naming, so `aria-label` on it is
  dropped or read inconsistently. The glyph keys are hidden from assistive
  technology so the name is not read twice.
- Inside a control, the words become part of its name: a menu item reads
  "Copy Command C", not "Copy ⌘C".
- `translateWithId` translates the spoken names.

## Getting started

Here's a quick example to get you started.

```bash
yarn add @carbon/react
yarn add @carbon-labs/react-keyboard-shortcut
```

### JS (via import)

```javascript
import { KeyboardShortcut } from '@carbon-labs/react-keyboard-shortcut/es/index';

function App() {
  return <KeyboardShortcut keys={['mod', 'K']} />;
}

export default App;
```

### SCSS

In your styles file import

```
@use '@carbon/react';
@use '@carbon-labs/react-keyboard-shortcut/scss/keyboard-shortcut';
```
