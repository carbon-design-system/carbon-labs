> and deployment of Carbon-based components.

## Getting started

Install `@carbon-labs/react-recipe-renderer` to use this package.

Renders JSON recipes: layouts, flows and widgets composed of real Carbon
components, on the Carbon grid, with Carbon spacing tokens and no literal
values. The recipes ship in this package (`recipes/*.recipe.json`) beside their
schema (`recipe.schema.json`), so a tool can read them from npm without
rendering anything.
