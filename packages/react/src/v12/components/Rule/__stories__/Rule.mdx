## Overview

A conversation needs a hairline between a day, a session or a compaction and the
turns around it, and that line should not be a part of the notice that names it,
so the notice can say anything. Carbon has no standalone divider component: its
Menu, Switcher and SideNav dividers are each a 1px `$border-subtle` rule. `Rule`
is that rule and nothing more; the nearest neighbour is the Menu divider.

## Getting started

Here's a quick example to get you started.

```bash
yarn add @carbon/react
yarn add @carbon-labs/react-rule
```

### JS (via import)

```javascript
import { Rule } from '@carbon-labs/react-rule/es/index';

function App() {
  return <Rule />;
}

export default App;
```

### SCSS

In your styles file import

```
@use '@carbon/react';
@use '@carbon-labs/react-rule/scss/rule';
```
