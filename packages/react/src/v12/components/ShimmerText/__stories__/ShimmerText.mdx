# Shimmer text

A label that shows live work: a band in the primary text sweeps through words
that rest a step quieter. It runs on the skeleton wave's angle.

<Canvas of={ShimmerTextStories.Default} />

## Motion

| Pattern        | Where                      | Values                                                                                                                     |
| -------------- | -------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Pass           | While `active`             | The band crosses from wholly before the words to wholly past them, standard-productive, then rests 500ms and passes again  |
| Speed          | By the words' length       | 0.09px/ms at 66px of words, 0.16px/ms at 381px, linearly between, held outside                                             |
| Band           | Each pass                  | Soft, 75% of the words' width along the sweep, between 96 and 240px; drawn on the words' own glyphs, the weight unchanged  |
| Colours        | Per theme                  | The band `$text-primary`, the rest `$text-secondary`; a host sets `--cds-shimmer-band-color` or `--cds-shimmer-rest-color` |
| Start          | Mount, or turning active   | The first pass sets off at once, from before the words                                                                     |
| Wave           | Labels that start together | One wave on the skeleton wave's 45° angle; a change of words keeps the phase                                               |
| Active off     | `active` false             | The band goes at once; the words' colour moves to the host's over fast-02, standard-productive, and back                   |
| Reveal         | `playShimmerReveal`        | Words arrive under one crossing at the label's own speed, without the rest; the first pass follows one rest after          |
| Off screen     | A hidden label             | The pass holds and comes back on its phase                                                                                 |
| Reduced motion | Every change               | Plain text in its host's colour; the reveal shows the words at once                                                        |

## Props beyond Carbon's

| Prop                | What it does                                                                                                   |
| ------------------- | -------------------------------------------------------------------------------------------------------------- |
| `active`            | Whether the band sweeps. Off, the label is plain text. Default on.                                             |
| `motion`            | Tuning, an object. Each key left out is the default.                                                           |
| `motion.shortSpeed` | The band's average speed for a short label, 66px of words, px per ms. Default 0.09.                            |
| `motion.longSpeed`  | Its speed for a long label, 381px; a length between takes a speed between. Default 0.16.                       |
| `motion.restMs`     | The rest between passes, ms, every label's. Default 500.                                                       |
| `motion.band`       | The band's width: px along the sweep, or a share of the label's width, kept between 96 and 240px. Default 75%. |
| `as`                | The element. Default a span.                                                                                   |
| `children`          | The words: a real stage of the work, never a stand-in.                                                         |

The band needs plain words; other children are plain text. The band is the
words' own fill, so assistive technology reads the words once. Slow motion
multiplies the pass.
