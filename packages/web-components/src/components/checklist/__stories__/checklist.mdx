## Overview

The Checklist tracks a user's progress much like Your Learning or WalkMe. Each
item in the list can be clickable, and each item has an icon that defines the
item's state as "not started", "in progress", "completed", "error", or
"disabled".

The component family is:

- `<clabs-checklist>` — the root container with header, body and footer
- `<clabs-checklist-group>` — a labelled section inside the body
- `<clabs-checklist-item>` — a single task row, optionally clickable
- `<clabs-checklist-icon>` — the status icon (used internally by
  `clabs-checklist-item`)
- `<clabs-checklist-chart>` — the donut-chart progress indicator (used
  internally by `clabs-checklist`)

### HTML

```html
<clabs-checklist
  title="Get started checklist"
  chart-value="0.33"
  chart-label="33% complete"
  view-all-label="View all (10)"
  toggle-label="Toggle"
  toggle-aria-label="Checklist toggle"
  open>
  <clabs-checklist-group title="Section label">
    <clabs-checklist-item
      label="Task name"
      status="completed"></clabs-checklist-item>
    <clabs-checklist-item
      label="Task name"
      status="in progress"
      clickable></clabs-checklist-item>
    <clabs-checklist-item
      label="Task name"
      status="not started"></clabs-checklist-item>
  </clabs-checklist-group>
</clabs-checklist>
```
